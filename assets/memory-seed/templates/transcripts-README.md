# transcripts/

Local copies of Claude Code session transcripts, written by the session-end hook.

- Repo mode: `YYYY-MM-DD/<session_id>.jsonl`
- Store mode: `<repo>/YYYY-MM-DD/<session_id>.jsonl`

Not committed. They may contain sensitive material. Never copy from them into memory without applying WRITE-RULES.md.
The dream pass records its last run in `.last-dream` (a date) and reads only newer transcripts.
