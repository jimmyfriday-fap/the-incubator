## Drift and hallucination guardrails

| Trap                                       | Why                               | Mechanical check                                                                           |
| ------------------------------------------ | --------------------------------- | ------------------------------------------------------------------------------------------ |
| Model sets values without saying why       | Every decision must be attributed | `attributionIssues` sends the turn back through the gate                                   |
| Model asks about lanes/CI/guardrails       | Packs fix them                    | `selectQuestions` drops `FIXED_BY_PACKS` keys; pack-fixed values are stripped              |
| Model re-asks answered questions           | Wastes a round                    | `selectQuestions` drops already-decided keys (seen live)                                   |
| More than 5 questions / 2 rounds           | Brief §5                          | engine trims to top 5 by impact; round 2 answers finalize without another call             |
| Hand-edited types drift from the schema    | Two sources of truth              | `types.gen.ts matches the schemas` test                                                    |
| Prompt drift invalidates fixtures silently | Replays would lie                 | keyed fixtures fail with the actual key; `INCUBATOR_FIXTURE_REKEY=1` rewrites deliberately |
| Real agent CLI on PATH leaks into tests    | Non-hermetic tests                | adapter tests set `PATH` to the fake CLI directory only                                    |
