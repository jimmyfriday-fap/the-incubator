# Memory index

Generated by `.memory/bin/memory index`. Do not hand-edit: change a file's `description:` instead.
Read this at the start of any non-trivial task, then open only the files you need.

## Platform (applies everywhere)

- `.memory/context/platform/architecture.md` · Components and how they connect; in a multi-repo system, one line per repo and every cross-repo edge. Read before structural changes.
- `.memory/context/platform/conventions.md` · Rules that hold everywhere: naming, data access, error handling, UI and styling constraints. Read before writing code.
- `.memory/context/platform/decisions.md` · Decisions that affect more than one repo, with reasons, newest first. Read before proposing an alternative approach.
- `.memory/context/platform/failures.md` · Mistakes that recur across repos, and their fixes. Read before debugging.

## Projects (one directory per repo)

- `.memory/context/projects/the-incubator/decisions.md` · Decisions local to the-incubator, newest first. Read before changing how the-incubator does something.
- `.memory/context/projects/the-incubator/failures.md` · Recurring mistakes in the-incubator and their fixes. Read before debugging the-incubator; append when you fix something likely to recur.
- `.memory/context/projects/the-incubator/overview.md` · What the-incubator is, its entry points, and exact build/run/test commands. Read first when working in the-incubator.
- `.memory/context/projects/the-incubator/status.md` · Current state of in-flight work in the-incubator. Read at session start for orientation.

## Skills (open the SKILL.md when the description matches your task)

- `.claude/skills/add-an-adr/SKILL.md` · Records a non-obvious decision as an architecture decision record. Use when a change picks between real alternatives or amends an earlier ADR.
- `.claude/skills/dream/SKILL.md` · Out-of-band curation of this system's memory. Reads recent session transcripts against the store and proposes evidence-backed changes as a PR. Run when asked to "dream" or "curate memory".
- `.claude/skills/memory-bootstrap/SKILL.md` · Populates a memory store from the codebase of one or more member repos, then reconciles shared knowledge into the platform tier. Run at install, when adding a member, or after a major restructure. Produces a PR, never a direct commit.
- `.claude/skills/sync-pack-copies/SKILL.md` · Refreshes the copies of the guard toolkit that live in the base template pack, and the golden manifests that hash them. Use after editing any script that scripts/packs-sync.mjs copies, or .claude/settings.json.
